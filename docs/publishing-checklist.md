# Public Release Checklist

The repository must remain private until every required item is complete.

## Technical verification

- [ ] Exact A9 Mega SKU and configuration are stated consistently.
- [ ] A technical maintainer has reproduced the complete setup.
- [ ] QA has completed two independent clean installations.
- [ ] All commands and scripts have been retested from the repository.
- [ ] Software and model versions are pinned.
- [ ] No unverified command is presented as production-ready.
- [ ] Benchmark prompts, settings, conditions, and measurement tools are documented.
- [ ] Known failures and manual steps are disclosed.

## Security and privacy

- [ ] No API keys, access tokens, passwords, cookies, or private URLs are committed.
- [ ] No Windows user names, device serial numbers, or internal network details are visible.
- [ ] Logs and screenshots have been reviewed for sensitive information.
- [ ] Download links point to trusted official or original project sources.
- [ ] Scripts do not silently disable security controls or download unreviewed executables.

## Licensing

- [ ] A license has been approved for GEEKOM-owned code and documentation.
- [ ] Every third-party tool and model has a recorded source and license.
- [ ] Model redistribution terms have been checked.
- [ ] No third-party model weights are uploaded without explicit permission.
- [ ] Required notices and attribution are included in `THIRD_PARTY_NOTICES.md`.
- [ ] Screenshots, logos, GIFs, and videos are owned or approved for publication.

## Brand and claims

- [ ] Product name, processor name, memory, storage, and OS are accurate.
- [ ] Platform TOPS and NPU TOPS are not confused.
- [ ] Measured results are tied to the tested configuration.
- [ ] No claim implies guaranteed performance across all configurations.
- [ ] Offline operation is qualified by the need to pre-install models and dependencies.
- [ ] Limitations and third-party dependencies are visible.
- [ ] Website URL, UTM parameters, and campaign code are approved.

## Repository readiness

- [ ] README quick start works for a new user.
- [ ] Installation, start, stop, and uninstall instructions are present.
- [ ] Issue templates and support expectations are configured.
- [ ] Social preview image is approved.
- [ ] Repository description and topics are finalized.
- [ ] Organization owners have reviewed repository access.
- [ ] Public visibility is enabled only by an internal GEEKOM owner.
